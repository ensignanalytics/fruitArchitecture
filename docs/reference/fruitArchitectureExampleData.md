# Load the bundled fruitArchitecture example data

Loads the synthetic differential-expression, annotation, count, and
design tables included with the installed package. These data are
intended for testing installation and demonstrating the package
workflow; they are not biological observations.

## Usage

``` r
fruitArchitectureExampleData()
```

## Value

A named list containing `deg_table`, `annotation`, `counts`, and
`design`.
